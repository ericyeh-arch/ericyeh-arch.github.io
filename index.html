用 Vibe Code 生成網頁，再用 GitHub Pages 免費上架

把 AI 產出的本機靜態網站，整理成可分享的公開網址。這個互動頁把影片重點拆成流程、提示詞、部署設定與驗收清單。

開始操作 下載 PPT
來源影片 程式猿（AFA）｜4:17｜2025-12-06

核心目標

先生成可部署的靜態網站，再讓 GitHub Pages 提供公開 URL。

01 AI 生成

用 Google Antigravity 或類似工具建立 HTML、CSS、JavaScript。

02 本機驗收

直接開啟 index.html，確認內容、版面與互動能運作。

03 公開部署

上傳 GitHub repository，啟用 Pages 後取得網址。
