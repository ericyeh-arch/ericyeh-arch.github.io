實作流程

Firebase + GitHub Pages 部署路徑

進度檢核

Step 1

貼上 Firebase SDK 設定

在 Gemini Canvas 或 Web App 程式碼中加入 Firebase 專案的 config，讓前端能連接 Authentication、資料庫或其他 Firebase 服務。

公開網站時請確認金鑰、網域與專案權限符合課堂示範用途。

Step 2

完成註冊與登入頁面

註冊頁面包含真實姓名、電子信箱與密碼；登入頁面包含電子信箱與密碼，並提供忘記密碼與管理頁面入口。

Step 3

建立 GitHub Repository 並發佈 Pages

建立新的 repository，將產出的 `index.html` 上傳，啟用 Pages 後取得公開網址，用來測試前端與 Firebase 是否能正常連線。

Step 4

回填 Firebase 授權網域

到 Firebase Authentication 的設定頁，加入 GitHub Pages 網域，避免登入或註冊時被授權網域擋下。
